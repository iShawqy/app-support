# App support

This page is for people who use the apps. It is the only file in this repository.

## Ask for help

Email [ibrahim.shawqy@outlook.com](mailto:ibrahim.shawqy@outlook.com).

Say which app you are using. Say whether something is broken or you want a new feature. Describe what you did and what you expected to happen.

## What you can expect

The apps can record what you do in the product, such as opening a screen or saving something you care about. You can also register with a username on that app. A request you send from inside an app is delivered by the app. This page does not take a form.
